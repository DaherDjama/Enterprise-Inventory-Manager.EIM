# Enterprise Inventory Manager (EIM)

Desktop inventory management application with CUMP calculation, margin analysis, and audit trails. Built with Python/SQLite, designed for Windows 10 32-bit.

## Features

- **Product Management**: Full CRUD operations with barcode support
- **Stock Movements**: Track entries, exits, and transfers
- **Financial Calculations**: CUMP, margins, profitability analysis
- **Inventory Control**: Physical inventory with variance tracking
- **Multi-user Support**: Role-based access (Admin, Storekeeper, Auditor)
- **Audit Trail**: Complete history of all stock modifications
- **Reports**: KPI dashboards, ABC analysis, export to Excel/PDF

## Tech Stack

- **Language**: Python 3.x
- **Database**: SQLite
- **UI**: Tkinter (Windows desktop)
- **Target**: Windows 10 32-bit
